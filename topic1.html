What is HTTP?

HTTP (Hypertext Transfer Protocol) is an application-layer protocol used to transfer hypermedia documents, such as HTML. It follows a client-server model where requests are sent by clients and responses returned by servers.

Request / Response Cycle

  1. Client opens connection and sends a request message.
  2. Server processes the request and returns a response message.
  3. Connection may be kept alive or closed depending on headers.

Example request headers

GET /index.html HTTP/1.1
Host: example.com
User-Agent: example-client/1.0
