Statelessness

HTTP is a stateless protocol: each request is independent, and the server does not keep client state between requests unless explicitly implemented (cookies, sessions).

Headers

Headers carry meta information (Content-Type, Content-Length, Authorization, Cache-Control). They shape how requests and responses are interpreted.

Status Codes

Status codes signal the result of the request. Ranges: 1xx informational, 2xx success, 3xx redirection, 4xx client error, 5xx server error.

Security (TLS)

Transport Layer Security (TLS) secures HTTP traffic; when used, the scheme becomes HTTPS and encrypts data between client and server.

Caching

Caching improves performance by storing responses with defined freshness. Cache headers control behavior (Expires, Cache-Control, ETag).

Further concepts (brief)

  • REST — architectural style on top of HTTP
  • WebSockets — different protocol for bidirectional comms
  • Content negotiation — selecting format via Accept headers
